# Papelaria Pouso Alegre — Amarelinha 💛

Este repositório faz parte do meu processo de aprendizado e desenvolvimento na área de programação.

Estou desenvolvendo um protótipo de site institucional para a **Papelaria Pouso Alegre**, carinhosamente conhecida como **Amarelinha**, com o objetivo de apresentar a papelaria, sua identidade, seus produtos e sua história.

Além de ser um projeto de desenvolvimento pessoal e profissional, é uma oportunidade de colocar em prática meus conhecimentos em desenvolvimento web, utilizando **HTML5 e CSS3**, enquanto aprimoro minhas habilidades e me preparo para implementar funcionalidades utilizando **JavaScript**.

### Tecnologias utilizadas e planejadas

- HTML5
- CSS3
- JavaScript (em aprendizado e implementação futura)

### Objetivos do projeto

- Praticar a estruturação de páginas com HTML.
- Aprimorar meus conhecimentos em CSS.
- Desenvolver layouts modernos e responsivos.
- Aprender JavaScript e implementar recursos interativos.
- Evoluir minhas habilidades em desenvolvimento web.
- Construir um projeto para meu portfólio profissional.

**Status:** Em desenvolvimento 🚧

Este projeto é um protótipo desenvolvido para fins de estudo, treinamento e evolução profissional. Cada etapa representa uma oportunidade de aprendizado, prática e aprimoramento das minhas habilidades como futuro desenvolvedor.
